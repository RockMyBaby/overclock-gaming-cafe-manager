# 🎮 Overclock Gaming Cafe Manager

A modern React-based management application built for **Overclock Gaming Cafe**.

The application helps manage gaming systems, game libraries, installed games, game ownership, pricing, and active gaming sessions — all from one easy-to-use dashboard.

Designed specifically for a gaming cafe with multiple PlayStation consoles, the system makes it easy for the cafe owner to manage which games are available on which console without editing any code.

---

## ✨ Features

### 🎮 Gaming System Management

Manage all gaming systems in one place.

Currently supports:

- 🎮 PS5-01
- 🎮 PS5-02
- 🎮 PS5-03
- 🎮 PS4-01

Each system can display:

- Console type
- Current status
- Installed games
- Current players
- Active gaming session
- Session duration

---

## 📚 Game Library

Maintain a complete catalog of all games available at the gaming cafe.

Each game contains:

- 🎮 Game Title
- 🕹 Platform (PS5 / PS4)
- 🎭 Genre
- 📦 Ownership Status
- 💿 Game Source
- 🖥 Installed Systems
- 🖼 Game Artwork

Games can be easily:

- Added
- Edited
- Removed
- Installed on multiple systems
- Marked as owned or not owned
- Assigned to different game sources

---
